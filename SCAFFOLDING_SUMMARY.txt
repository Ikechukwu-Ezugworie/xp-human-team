================================================================================
PRE-COMMIT HOOK SETUP
================================================================================

The repository has a pre-commit hook that enforces commit message format:

   Format: SPRINT<num>-STORY<num>-[AI:NO]-<description>
   
   ✅ SPRINT1-STORY4-[AI:NO]-implement login
   ❌ SPRINT1-STORY4-[AI:YES]-implement login (REJECTED)
   ❌ implement login (REJECTED - missing format)

The hook is configured in .pre-commit-config.yaml.

To install (Day 1 setup):
   cd /path/to/xp-ai-experiment-control
   chmod +x .git/hooks/pre-commit

================================================================================
KEY RULES TO ENFORCE
================================================================================

1. NO AI TOOLS
   - GitHub Copilot disabled in VS Code
   - ChatGPT web interface not used
   - No Gemini, Tabnine, Codeium, or similar
   - All code written manually by human developers

2. TDD (Test-Driven Development)
   - Write test FIRST (RED)
   - Write minimal code to pass (GREEN)
   - Refactor without changing behavior
   - Commit order: test commit, then implementation commit

3. PAIR PROGRAMMING
   - 2 pairs of 2 developers
   - Partners rotate daily
   - Driver and Navigator roles
   - Switch roles every 15 minutes (use timer)

4. COMMITS
   - Format: SPRINT<num>-STORY<num>-[AI:NO]-<description>
   - Pre-commit hook enforces this
   - Atomic, well-documented commits
   - Meaningful commit messages explaining the "why"

5. CODE QUALITY
   - All tests pass before committing
   - SonarQube quality gate must pass
   - GitHub Actions CI must pass
   - No broken builds ever reach main

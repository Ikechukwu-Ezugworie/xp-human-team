# Running the XP Chat Application

This guide will walk you through setting up and running both the backend API and frontend UI for the chat application generated by the XP team simulation.

## Prerequisites

- **Python** 3.9+ (for backend)
- **Node.js** 16+ (for frontend)
- **npm** 7+ (comes with Node.js)
- **Git** (already installed)

Verify versions:
```bash
python --version    # Should be 3.9+
node --version      # Should be 16+
npm --version       # Should be 7+
```

## Part 1: Backend Setup

### Step 1: Navigate to Backend Directory
```bash
cd /Users/mac/Documents/Innopolis/Thesis/Thesis\ LLM\ SE/experiment/xp-human-team/backend
```

### Step 2: Create Virtual Environment
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

You should see `(venv)` at the start of your terminal prompt.

### Step 3: Install Dependencies
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

This installs:
- **fastapi** — Web framework
- **uvicorn** — ASGI server
- **sqlalchemy** — ORM for database
- **pyjwt** — JWT token handling
- **passlib + bcrypt** — Password hashing
- **pytest** — Testing framework
- Plus others (see requirements.txt)

Verify installation:
```bash
python -c "import fastapi; print(f'FastAPI {fastapi.__version__} installed')"
python -c "import sqlalchemy; print(f'SQLAlchemy {sqlalchemy.__version__} installed')"
```

### Step 4: Set Environment Variables (Optional)
Create a `.env` file in the `backend/` directory:
```bash
cat > .env << EOF
SECRET_KEY=your-secret-key-for-jwt-tokens
DATABASE_URL=sqlite:///./chat.db
CORS_ORIGINS=http://localhost:3000
EOF
```

Or use defaults (the app will work without `.env`).

### Step 5: Initialize Database
The database (SQLite) is created automatically when the app starts. You can verify by checking for `chat.db` after running.

### Step 6: Run Backend Server
```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

**Expected Output:**
```
INFO:     Uvicorn running on http://0.0.0.0:8000
INFO:     Application startup complete
```

The API is now available at:
- **Base URL**: `http://localhost:8000`
- **API Docs**: `http://localhost:8000/docs` (interactive Swagger UI)
- **Alternative Docs**: `http://localhost:8000/redoc` (ReDoc)
- **Health Check**: `http://localhost:8000/health`

### Backend API Endpoints

Once running, you can interact with the API:

**Authentication:**
```bash
# Register a user
curl -X POST http://localhost:8000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username": "alice", "password": "password123"}'

# Response:
# {"access_token": "eyJ0eXAiOiJKV1QiLCJhbGc...", "token_type": "bearer"}

# Login
curl -X POST http://localhost:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username": "alice", "password": "password123"}'
```

**Rooms:**
```bash
# List rooms
curl -X GET http://localhost:8000/api/rooms

# Create a room (requires auth token)
curl -X POST http://localhost:8000/api/rooms \
  -H "Authorization: Bearer YOUR_TOKEN_HERE" \
  -H "Content-Type: application/json" \
  -d '{"name": "general", "description": "General chat"}'

# Get specific room
curl -X GET http://localhost:8000/api/rooms/1
```

**Messages:**
```bash
# Send message to room (requires auth)
curl -X POST http://localhost:8000/api/messages/1 \
  -H "Authorization: Bearer YOUR_TOKEN_HERE" \
  -H "Content-Type: application/json" \
  -d '{"content": "Hello, everyone!"}'

# Get messages from room
curl -X GET "http://localhost:8000/api/messages/1?skip=0&limit=50"
```

**View Interactive API Docs:**
- Open browser to `http://localhost:8000/docs`
- You can test all endpoints directly in the browser

## Common Issues & Troubleshooting

### Backend Issues

**Error: `ModuleNotFoundError: No module named 'fastapi'`**
- Solution: Activate virtual environment: `source venv/bin/activate`
- Or install requirements: `pip install -r requirements.txt`

**Error: `Address already in use`** (port 8000)
- Solution: Another app is using port 8000
- Kill it: `lsof -i :8000` then `kill -9 <PID>`
- Or change port: `uvicorn app.main:app --port 8001`

**Error: `sqlite3.OperationalError: attempt to write a readonly database`**
- Solution: Check file permissions in backend directory
- Run: `chmod 755 backend/`

**Database file not created**
- Solution: The database is created automatically on first run
- Check: `ls -la backend/chat.db`
- If missing, it will be created when the server starts

### Frontend Issues

**Error: `npm ERR! Cannot find module`**
- Solution: Reinstall dependencies: `npm install`
- Clear cache: `npm cache clean --force`

**Error: Port 3000 already in use**
- Solution: Kill the process using port 3000
- Run: `lsof -i :3000` then `kill -9 <PID>`
- Or npm will prompt to use a different port (say yes)

**Blank screen or cannot connect to backend**
- Solution: Verify backend is running on `http://localhost:8000`
- Check `.env.local` has correct `REACT_APP_API_URL`
- Open browser DevTools → Network tab to see requests

**WebSocket connection fails**
- Solution: Backend must be running (step above)
- Check browser console for errors
- WebSocket URL should be `ws://localhost:8000/ws/{room_id}`

## Full Application Flow

1. **User registers** → Backend creates user with hashed password → JWT token returned
2. **User logs in** → Backend verifies credentials → JWT token returned
3. **User creates room** → Backend stores room in database
4. **User joins room** → Backend adds user to room membership
5. **User sends message** → Backend stores message, broadcasts via WebSocket
6. **Other users receive message** → WebSocket connection gets JSON data, React updates UI
7. **User views history** → Backend returns last 50 messages with pagination

## Architecture Overview

### Backend Stack
```
FastAPI (HTTP + WebSocket server)
├── SQLAlchemy ORM
├── SQLite database
├── JWT authentication
├── CORS middleware
└── Routers: auth, rooms, messages
```

### Frontend Stack
```
React 18
├── Components: Login, Chat, UserList
├── Hooks: useWebSocket (custom)
├── Services: api (axios)
├── Styles: CSS (responsive)
└── WebSocket client
```

### Data Flow
```
Frontend (React) 
  ↓ HTTP (REST)
Backend (FastAPI)
  ↓
Database (SQLite)

Frontend (React)
  ↓ WebSocket (ws://)
Backend (FastAPI)
  ↓ Broadcast to connected clients
All Users
```
